# Company Assistant

Корпоративный помощник для браузера, Windows и macOS. Разрабатывается для самостоятельного размещения на VPS; генерация изображений в текущую версию не входит.

## Статус

Первая версия для пилотного запуска: веб-интерфейс, сервер, админ-панель и Electron-клиент реализованы. Интеграционные тесты запускаются локально и в GitHub Actions, вход и админ-панель проверены в браузере. Тестовые установщики Windows x64 и macOS (Intel / Apple Silicon) успешно собраны в GitHub Actions, без настроенной цифровой подписи и нотариализации. API-ключ и рабочие данные никогда не добавляются в Git.

До рабочего использования нужны VPS/домен, ключ OpenAI, проверка настоящего API-запроса, тест камеры на целевых устройствах, нагрузочная проверка и подпись установщиков. Ответы OpenAI в тестах заменены контролируемым провайдером; платные запросы без ключа не выполнялись.

## Согласованные возможности

- Вход по логину / почте и паролю; учётки создаёт администратор.
- Чат с GPT-6 Luna, документы и фото, снимок с камеры перед отправкой.
- Только один последний успешный запрос с ответом и вложениями на аккаунт.
- Копирование ответа, скачивание файлов, индикатор обработки и ошибки.
- Администратор управляет пользователями, лимитами и сеансами; видит расход и активные подключения.
- Разные сотрудники работают одновременно; один активный запрос на аккаунт, включая все его устройства.
- Онлайн определяется по heartbeat за последние 120 секунд. Сеансы не равны физическим устройствам. ОС и браузер определяются приблизительно по User-Agent.
- IP определяется сервером. География — опциональная локальная GeoIP-база, без отправки адресов внешнему сервису.

## Лимиты по умолчанию

20 МиБ на файл, 5 файлов и 50 МиБ суммарно. Вход — 32 000 токенов, выход — 8 000, сутки — 300 000. Дополнительный дневной денежный предел по умолчанию — $1 на сотрудника, изменяется администратором.

Предварительный подсчёт текста консервативен: UTF-8-байты как верхняя оценка токенов плюс запас на структуру запроса и изображения. До интеграции точного токенизатора длинный текст может отклоняться раньше фактических 32 000 токенов. После ответа учитывается usage провайдера. Стоимость — оценка по настраиваемым стандартным тарифам без скидок за кэш, не официальный счёт OpenAI. Неопределённые по расходу запросы сохраняют резерв.

## Сервер

Рекомендованный старт для 15–20 сотрудников: 4 vCPU, 8 ГБ RAM, 80 ГБ SSD/NVMe, Ubuntu 24.04 LTS. GPU не требуется. Нужны домен/HTTPS, API-ключ и резервное копирование.

## Локальная разработка

Node.js 24+, pnpm. Установите зависимости, скопируйте `.env.example` в `.env`, задайте параметры. Секреты храните только в `.env` / окружении сервера.

```sh
pnpm install
pnpm admin
pnpm start
```

Откройте `http://localhost:3100`. Скрипт `pnpm admin` создаёт администратора с одноразовым временным паролем. На первом входе пароль нужно сменить. `pnpm test` запускает проверки изоляции аккаунтов, квот, конкурентности, хранения последнего результата, отзыва сеансов и обработки файлов.

- [Установка на VPS](deploy/README.md)
- [Сборка Windows и macOS](desktop/README.md)
- [Готовые тестовые установщики — запуск 36106152852](https://github.com/turn1k/company-assistant/actions/runs/36106152852) (артефакты хранятся до 9 октября 2026 г.; после этого запустить сборку снова).

Исходники публикуются без `node_modules`, `.env`, базы, загрузок и установщиков. Установщики сохраняются отдельно в `desktop/dist` или артефактах GitHub Actions.

## Конфиденциальность

Содержимое запроса и вложений передаётся OpenAI при отправке. Удаление предыдущего результата относится к активной базе приложения и файловому хранилищу. Резервные копии, SQLite WAL и правила хранения провайдера требуют отдельной политики; не обещается физическое уничтожение всех копий. Статистика расходов хранится отдельно от текстов.

## GPT-6 Luna

Сервер использует OpenAI Chat Completions, модель `gpt-6-luna`, `reasoning_effort: none`, `max_completion_tokens`, стандартную обработку и `store: false`. API-ключ задаётся только на сервере через `OPENAI_API_KEY`; `OPENAI_MODEL` по умолчанию равен `gpt-6-luna`. Старые переменные DEEPSEEK больше не используются. После изменения env перезапустите службу.

Стандартные цены: $0.10 за миллион входных и $0.50 за миллион выходных токенов. Подсчёт включает весь `completion_tokens`, а не только видимый текст. Для фото используется `detail: high` и предварительный резерв 8192 токена на изображение до сверки реального usage: это оценка, не точный токенизатор Luna и не гарантия верхней границы. Несколько фотографий могут потребовать большего лимита на запрос.

`store: false` отключает сохранение completion как объекта API, но не отменяет политику хранения данных провайдера. История приложения по-прежнему содержит один последний успешный результат.

Документация: [модель и тарифы](https://developers.openai.com/api/docs/models/gpt-6-luna), [подсчёт токенов](https://developers.openai.com/api/docs/guides/token-counting). Реальный API без ключа не проверялся; транспортные тесты используют подставной HTTP-ответ.

## Ranvik и скачиваемые документы

В `.env` укажите `OPENAI_BASE_URL=https://api.ranvik.ru/v1` и ключ Ranvik в `OPENAI_API_KEY`. `OPENAI_MODEL` — точный ID из каталога, доступный вашему ключу. Код сохраняет выбранный `gpt-6-luna`, автоматической замены модели нет. На 30.09.2026 доступность `gpt-6-luna` подтверждена реальным запросом Ranvik. Документация: https://api.ranvik.ru/docs и https://api.ranvik.ru/docs/models.

Укажите `INPUT_USD_PER_MILLION` и `OUTPUT_USD_PER_MILLION` по тарифу посредника в долларовом эквиваленте. Старые цены прямого OpenAI к Ranvik не относятся. Для расходов и бюджетов в рублях задайте DISPLAY_CURRENCY=RUB и фиксированный ACCOUNTING_RUB_PER_USD; подробности — в deploy/README.md. При нестандартном API без явно заданных тарифов запросы блокируются, чтобы не считать расходы по чужим ценам. API-ключ остаётся на сервере. Совместимый HTTP-контракт проверен тестами и реальным запросом Ranvik; скачивание DOCX/XLSX проверено через приложение.

Под последним ответом доступны Word (DOCX), Excel (XLSX), TXT, Markdown и печать / сохранение PDF средствами браузера. DOCX включает заголовки, абзацы и Markdown-таблицы. XLSX содержит полный текст на листе «Ответ» и каждую Markdown-таблицу на отдельном листе. Значения сохраняются текстом; формулы, макросы, графики и выполнение сгенерированного кода не поддерживаются. CSV и JSON доступны, если модель вернула соответствующий текстовый файл. Это создание документов из содержимого ответа, а не редактор произвольных шаблонов Office. PDF использует печатное представление текста ответа.

DOCX/XLSX создаются по запросу без дополнительного вызова модели и без сохранения новых копий на сервере. Старый экспорт недоступен после замены последнего результата. Доступ проверяется по аккаунту и ID ответа; администратор не получает доступ к чужим ответам через экспорт. Скачанные сотрудником копии остаются на его устройстве.

На телефоне меню «Аккаунт» показывает дневной лимит, открывает последний запрос, смену пароля и выход. Формы имеют шрифт 16px и кнопки не ниже 44px. Проверка размеров браузера не заменяет проверку камеры и загрузки файлов на настоящих iOS/Android.
