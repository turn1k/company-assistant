# Развёртывание на VPS

Рекомендуемый старт: Ubuntu 24.04 LTS, 4 vCPU, 8 ГБ RAM, 80 ГБ SSD/NVMe. Это оценка для пилота, не гарантия пропускной способности. Модель DeepSeek вызывается по HTTPS, GPU не нужен. Для камеры в браузере обязателен HTTPS (кроме localhost).

## Подготовка

1. Установить Node.js 24 LTS из официального источника, pnpm 11.25.0, Git и Caddy. Проверить путь Node в unit-файле.
2. Создать системного пользователя `assistant` без интерактивного входа и каталог `/var/lib/company-assistant` с владельцем `assistant` и правами 700.
3. Клонировать `https://github.com/turn1k/company-assistant.git` в `/opt/company-assistant`. Приложение запускается ровно одним процессом: ограничение конкурентности использует память этого процесса. Не запускать несколько реплик / cluster без распределённой блокировки.
4. В корне проекта выполнить `pnpm install --frozen-lockfile --prod`.
5. Скопировать `deploy/server.env.example` в `/etc/company-assistant.env`, задать реальный домен, ключ DeepSeek и часовой пояс. Права файла 600, владелец root. Не включать ключ в Git и команды shell с историей.
6. Создать первого администратора: `sudo -u assistant env DATA_DIR=/var/lib/company-assistant node /opt/company-assistant/scripts/create-admin.mjs`. Команда покажет одноразовый временный пароль. После первого входа его нужно заменить.
7. Установить unit из `company-assistant.service`, затем `systemctl daemon-reload` и `systemctl enable --now company-assistant`.
8. Направить DNS домена на VPS. Указать домен в Caddyfile, проверить конфигурацию `caddy validate`, перезагрузить Caddy. Открыть 80/443; доступ SSH ограничить согласно политике компании. Порт 3100 доступен только локально.

`TRUST_PROXY_LOOPBACK=true` допустимо только за доверенным прокси на loopback. Прямой внешний доступ к Node не предоставлять. Пример рассчитан на Caddy на том же сервере; при Docker/Cloudflare/другом прокси схему доверия требуется адаптировать, иначе IP будут определяться неверно.

## Проверка после запуска

- `/health` отвечает `{ "ok": true }`; вход администратора работает по HTTPS.
- Создать тестового сотрудника, сменить временный пароль, отправить короткий запрос в DeepSeek и документ. Проверить usage и стоимость в кабинете провайдера.
- Проверить доступ к камере в браузере, Windows и macOS; запрет камеры должен оставлять возможность прикрепить файл.
- Проверить второй браузер/устройство в админ-панели, heartbeat, отзыв сеанса и блокировку.
- Перед использованием 20 сотрудниками провести тест с представительными PDF/XLSX: параллельная обработка тяжёлых документов расходует память. Настройка `MAX_CONCURRENT_REQUESTS` ограничивает нагрузку на весь сервер, стандартно 20.

## GeoIP

Страна и город определяются опционально по локальной базе MaxMind GeoLite2 City (`GEOIP_DATABASE=/var/lib/company-assistant/GeoLite2-City.mmdb`). Базу предоставляет владелец сервера по условиям MaxMind, обновление нужно настроить отдельно. Без базы показываются IP и «GeoIP не подключён». VPN/прокси меняют географию. Приложение не собирает GPS и не отправляет IP внешнему сервису.

## Резервное копирование и обновление

Согласовать период хранения резервных копий. Для согласованного снимка остановить сервис, скопировать весь `/var/lib/company-assistant` в защищённое резервное хранилище и запустить сервис. Проверять восстановление. В копиях могут оставаться предыдущие запросы; ограничение «один последний» действует на активные данные приложения. `audit` и `usage` не содержат текста запросов; журналы входа и статистика также нуждаются в сроке хранения.

Перед обновлением сделать резервную копию, остановить сервис, получить изменения Git, установить зависимости по lock-файлу, запустить сервис и выполнить проверку входа/запроса. Секреты остаются в `/etc/company-assistant.env`, данные — в `/var/lib/company-assistant`.

## Тарифы и ограничения

По умолчанию используется `deepseek-flash`. Цены в env — консервативные пиковые цены за миллион токенов; меняя модель, обязательно изменить цены и подтвердить поддержку изображений. Скидки за cache hit и непиковое время не вычитаются: UI показывает верхнюю оценку расходов. Неопределённый результат при timeout сохраняет максимальный резерв и отмечается в админ-панели.

Точный токенизатор текущей модели пока не интегрирован: приём текста использует консервативную оценку по UTF-8-байтам. Длинные документы могут отклоняться раньше лимита модели. Текст не обрезается. PDF без текстового слоя требуют отдельной загрузки страниц как фото; автоматического OCR всего PDF пока нет. XLSX читается как данные ячеек, без выполнения формул или макросов. Ответы можно экспортировать в TXT/Markdown и текстовые файлы TXT/MD/CSV/JSON, сформированные моделью; редактирование бинарных офисных документов пока не реализовано.
