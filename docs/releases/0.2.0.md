Веб-приложение: https://companyassistant.ru

- Работа с текстом, фотографиями, PDF (включая сканы), Word и Excel через Ranvik / gpt-6-luna.
- Скачивание ответов в Word и Excel; хранение только последнего результата.
- Администрирование сотрудников, блокировка аккаунтов, лимиты и учёт расходов.
- Информация об устройствах и приблизительном местоположении по IP.
- Адаптация для мобильного браузера, исправление экрана входа на iPhone.
- Тёмная тема и «Запомнить меня» на 30 дней; устранено краткое появление страницы входа при восстановлении сеанса.
- Резервные копии на VPS и информация о состоянии сервиса в админ-панели.

Установщики:
- Windows x64: файл .exe.
- macOS Apple Silicon: arm64.dmg; Intel: x64.dmg.
- ZIP для macOS и SHA256SUMS.txt также приложены.

Ограничения: установщики без цифровой подписи и нотариального заверения Apple. Сборки macOS созданы успешно, запуск на реальном Mac ещё не проверен. Полный цикл установки/удаления Windows также ещё не проверен. Доставка уведомлений Telegram остаётся нерешённой. Тёмную тему и «Запомнить меня» пользователь проверяет самостоятельно.

Проверки веб-версии: 21 автоматический тест, проверка резервного копирования, одновременные запросы 20 тестовых пользователей, реальные запросы к Ranvik, чтение сканированного PDF и скачивание DOCX/XLSX. Проверка iPhone выполнена пользователем.
